# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

投递必须声明纸型克重（g/m²），克重要落在印刷员设定的闭区间 `[下限, 上限]` 内，边界合格，落在外面直接退回（HTTP 422），不进队列。每次送检与改克重都把**克重原文快照**追加进履历；事后改行的克重，履历里早先那笔数字保持原样。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可设克重区间、可改行克重 |
| checker | check123456 | 只看：可翻克重区间与履历，改不了区间，不能投递 |

## 页面

顶栏两页：

- **复核台**：送复核（必带克重）、看状态结论；印刷员可在表内改行的克重。
- **纸型克重**：分三区
  - 区间设置：印刷员改闭区间，只读账号只见当前值；
  - 送检克重栏：克重优先的投递入口，区间外即时提示退回；
  - 克重履历：送检/改克重事件流水，每笔记下当时的克重原文与当时的闭区间。

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5、克重 100 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮；在「纸型克重」页能看到区间和履历，没有保存区间按钮。
4. 顶栏打开「纸型克重」，区间设成 80 ~ 120：
   - 送检克重栏填 **100** → 收下；
   - 填 **50** → 提示「克重 50 不在闭区间 [80, 120] 内，退回」，不入队；
   - 填边界 80、120 都收下。
5. 在复核台把某行克重从 100 改成 110，履历多出一笔「改克重 110」，早先「送检 100」那笔仍是 100。
6. 改成区间外（如 50）同样被退回，行上克重与履历都不变。
