# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

顶栏点「纸型克重」拉开克重页，分区间设置、送检克重栏、克重履历三块：

- 投递必须声明纸型与克重，克重落在印刷员设定的闭区间内才收下，落在外面就退回。
- 每次投递与改克重都往履历里加一条，履历只增不改；事后改某一行的克重，履历里早先那笔数字仍保持原样。
- checker 能翻克重区间与履历，改不了区间。


## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. 顶栏点「纸型克重」，printer 把区间设成 80–120；投 100 应收下，投 50 应退回。
5. 改掉某一行的克重后，克重履历里早先那笔数字仍保持原样。
6. checker 打开纸型克重页能翻区间与履历，但没有保存区间的入口。
